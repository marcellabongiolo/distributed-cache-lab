## 🔬 About This Repository

Welcome to my **distributed-cache-lab**! This repository explores system performance optimization by implementing an **LRU (Least Recently Used)** cache eviction mechanism in Python, ensuring constant time complexity ($O(1)$) for reads and writes.

### 📂 What You Will Find Here:
* **LRU Eviction Algorithm:** Automatically discarding the least accessed data when memory limits are reached.
* **Optimized Data Structures:** Combining Hash Maps and Doubly Linked Lists for maximum speed.
* **Clean Engineering:** Modular, well-documented code following enterprise software standards.
